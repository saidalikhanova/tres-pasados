# Tres pasados

Тренажёр испанских прошедших времён (pretérito indefinido, imperfecto, perfecto) по учебнику Vitamina B1, unidades 1–2.

- `index.html` — исходник тренажёра (он же публикуется как claude.ai artifact).
- `build_pwa.py` — собирает из него PWA в `docs/`: manifest, офлайн-режим, иконки.
- `docs/` — то, что раздаёт GitHub Pages.

Обновить: поправить `index.html` → `python3 build_pwa.py` → commit и push.
